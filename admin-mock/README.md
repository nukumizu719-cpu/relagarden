# 管理画面UI 静的モック

これは**見た目と操作の流れを確認するためだけ**のモックです。

## これは何ではないか

- ❌ ログイン機能では**ありません**（パスワードを入れても誰でも通ります）
- ❌ アップロード機能では**ありません**（画像はサーバーへ送られません）
- ❌ 公開機能では**ありません**（ホームページには反映されません）
- ❌ 本番へ設置してはいけません

## これは何か

- ✅ 谷口さんに「こういう画面になります」と見せて、先に意見をもらうためのもの
- ✅ ボタンの大きさ・言葉づかい・入力項目の順番を決めるためのもの
- ✅ iPhone SafariとWindows Chrome / Edgeでの見え方を確かめるためのもの

## 開き方

`index.html` をブラウザーで開くだけです。サーバーは不要です。

```bash
open admin-mock/index.html
```

## 本番との関係

本番の管理画面は、XserverのPHP・セッション・DBが使えることを確認したあとに、
別途サーバー側で実装します。仕様は [ADMIN_IMAGES_API.md](../docs/ADMIN_IMAGES_API.md) にあります。

このモックのHTML / CSSは、本番実装のときに見た目の下敷きとして使えます。
